# Pistes

Notées, pas engagées. Une piste devient une issue le jour où on la travaille, et sort alors de ce fichier.

- **Une sortie JSON à côté du texte.** Le design la laisse au constructeur ; le cadrage la remet à plus tard, le texte étant fait pour une session. Déclencheur : un usage par un programme, et non par une session.
- **Les options d'une liste déroulante fermée.** L'essai de `pupitre` du 2026-11-21 ne les voyait pas ; le clavier puis `valeur` y suffisent. Déclencheur : un essai qui doit lire toutes les options sans les parcourir.
